🧠 دستیار هوش مصنوعی محلیON-DEVICE · WEBGPU

پس از تأیید تو، یک مدل زبانی واقعی روی GPU دستگاهت بارگذاری می‌شود و فقط از شواهد بازی انتخاب‌شده برای توضیح و فرضیه‌سازی استفاده می‌کند.

مدل اختیاری است؛ نخستین دانلود می‌تواند چندصد مگابایت باشد و حدود ۱ گیگابایت حافظه GPU لازم داشته باشد. در دستگاه ضعیف فعالش نکن. هیچ کلید API لازم نیست.

غیرفعال؛ سایت بدون دانلود مدل زبانی هم کار می‌کند.
مدل فقط آمار ارائه‌شده را می‌بیند؛ قدرت تاکتیکی، xG یا Tracking بازی آینده را نمی‌داند. LLM ممکن است اشتباه کند.
